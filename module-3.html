PART A

Dictionaries in Python

A dictionary is a mutable collection of key-value pairs. It stores related information using unique keys, making values easy to retrieve and update.

01

About Dictionaries and Creating a Dictionary

Each item contains a key and its corresponding value. Keys must be unique and immutable (such as strings, numbers and tuples). Values can be of any data type. Dictionaries are mutable and are written using curly braces { }.

Creating a dictionary 
student = {
    "name": "Kiran",
    "age": 35,
    "department": "CSE"
}
print(student)
OUTPUT{'name': 'Kiran', 'age': 35, 'department': 'CSE'}
02

Accessing Dictionary Values

Values are accessed using their keys. Syntax: dictionary[key]. Accessing a missing key with square brackets raises a KeyError. The get() method safely returns None or a supplied default.

Access values with keys and get() 
student = {"name": "Kiran", "age": 35, "department": "CSE"}
print(student["name"])
print(student["age"])
print(student.get("email"))
print(student.get("email", "Not available"))
OUTPUTKiran
35
None
Not available
03

Adding and Updating Dictionary Items

Assigning a value to a new key adds a key-value pair. Assigning a value to an existing key updates that value.

Add a department and update age 
student = {"name": "Samarth", "age": 5}
print(student)
student["department"] = "School"
student["age"] = 6
print(student)
OUTPUT{'name': 'Samarth', 'age': 5}
{'name': 'Samarth', 'age': 6, 'department': 'School'}

Traversing a Dictionary

A for loop can access keys, values or key-value pairs. Use keys(), values() and items() for explicit traversal.

07

Dictionary Aliasing and Copying

Aliasing: two or more variables refer to the same dictionary object. A change through one variable is visible through the other.

Aliasing example 
student1 = {"name": "Kiran", "age": 35}
student2 = student1
student2["age"] = 36
print(student1)
print(student2)
OUTPUT{'name': 'Kiran', 'age': 36}
{'name': 'Kiran', 'age': 36}

Copying: use copy() or dict() to create a separate shallow copy. Top-level changes in the copy do not change the original. A shallow copy still shares nested mutable objects. Use copy.deepcopy() when an independent deep copy is required.

Copying a dictionary 
original = {"name": "Kiran", "age": 35}
copied = original.copy()
copied["age"] = 36
print("Original:", original)
print("Copied:", copied)
OUTPUTOriginal: {'name': 'Kiran', 'age': 35}
Copied: {'name': 'Kiran', 'age': 36}
08

Counting Frequency Using a Dictionary

A dictionary can count how many times each item occurs. The first occurrence creates an entry; repeated occurrences increment its count.

Character frequency 
word = "banana"
frequency = {}
for letter in word:
    if letter in frequency:
        frequency[letter] += 1
    else:
        frequency[letter] = 1
print(frequency)
OUTPUT{'b': 1, 'a': 3, 'n': 2}

NumPy – Numerical Python

NumPy is a Python library used for numerical and scientific computing. It provides efficient multidimensional arrays and mathematical operations.

09

Important features: multidimensional ndarray, efficient mathematical operations, indexing, slicing, reshaping, masking, broadcasting, linear algebra and statistics.

Shape and Attributes of a NumPy Array

shape gives the size along each dimension; ndim gives the number of dimensions; size gives the total number of elements.

Inspect array attributes 
import numpy as np
a = np.array([10, 20, 30, 40])
b = np.array([[1, 2, 3],
              [4, 5, 6]])
print(a.shape)
print(b.shape)
print(b.ndim)
print(b.size)
OUTPUT(4,)
(2, 3)

a.shape = (4,) means four elements in one dimension. b.shape = (2, 3) means two rows and three columns.

11

Reshaping an Array

The reshape() function changes the shape without changing the data. The new shape must be compatible with the total number of elements.

Reshape one-dimensional array 
import numpy as np
a = np.array([1, 2, 3, 4, 5, 6])
b = a.reshape(2, 3)
print(b)
OUTPUT[[1 2 3]
[4 5 6]]

13

NumPy Masking (Boolean Masking)

Masking selects array elements based on a condition. The condition produces a Boolean array of True and False values. True indicates that an element satisfies the condition.

Select marks greater than or equal to 50 
import numpy as np
marks = np.array([45, 78, 32, 90, 65])
mask = marks >= 50
print(mask)
print(marks[mask])
print(marks[marks >= 50])
OUTPUT[False True False True True]
[78 90 65]
[78 90 65]

Multiple conditions use & (AND), | (OR), and ~ (NOT). Put parentheses around each condition.

Multiple conditions 
import numpy as np
marks = np.array([35, 45, 60, 75, 90])
print(marks[(marks >= 40) & (marks <= 75)])
OUTPUT[45 60 75]
14

Broadcasting in NumPy

Broadcasting allows operations on arrays with different but compatible shapes without manually repeating values. Compare dimensions from right to left. Two dimensions are compatible when they are equal or one of them is 1. Otherwise NumPy raises a ValueError.

Scalar and array broadcasting 
import numpy as np
a = np.array([10, 20, 30])
print(a + 5)

b = np.array([1, 2, 3])
c = np.array([10, 20, 30])
print(b + c)

matrix = np.array([[1, 2, 3],
                   [4, 5, 6]])
row = np.array([10, 20, 30])
print(matrix + row)
OUTPUT[15 25 35]
[11 22 33]
[[11 22 33]
[14 25 36]]
Shapes (2, 3) and (2, 2) are not compatible for element-wise broadcasting.

PART C

Files in Python

File handling allows Python programs to create, open, read, write, append and manage data stored permanently on a storage device.

16

About Files, File Categories and Opening a File

Text files store readable characters (such as .txt, .csv, .py). Binary files store bytes (such as .jpg, .png, .pdf, .mp3).

Syntax: file_object = open("filename", "mode").

ModeDescription
rRead an existing file.
wWrite; creates or overwrites existing content.
aAppend data at the end of a file.
xCreate a new file; raises an error if it exists.
bBinary mode modifier.
tText mode modifier; default mode.
r+Read and write an existing file.
w+Read and write; overwrites or creates the file.
a+Read and append; creates the file if needed.
Open and close a file 
file = open("sample.txt", "r")
file.close()
The file must exist when it is opened in read mode. Opening an existing file in w mode erases its previous content.
17

Writing a File and Using the with Statement

The write() method writes text into a file. The newline character \n moves following text to a new line. The close() method closes a manually opened file and flushes buffered data.

Write a text file 
file = open("first.txt", "w")
file.write("Welcome to Python File Handling.\n")
file.write("This is our first file.")
file.close()
FILE CONTENT · first.txtWelcome to Python File Handling.
This is our first file.

The with statement is recommended. It automatically closes the file when the indented block finishes, including when an exception occurs.

Recommended with statement 
with open("first.txt", "w") as file:
    file.write("Python is easy to learn.")
print("File written successfully.")
OUTPUTFile written successfully.

Reading Files: read(), readline(), readlines() and for Loop

Read one line at a time

File handling is useful.

Read using a for loop 
with open("first.txt", "r") as file:
    for line in file:

Read the entire file

Appending Data and Working with Binary Files

Append mode (a) adds new content at the end without deleting existing content.

Append content 
with open("first.txt", "a") as file:
    file.write("\nWelcome to BITM.")
print("Data appended.")
OUTPUTData appended.

Binary files store information as bytes rather than ordinary readable text. Examples include images, audio, video and PDF documents. Binary modes: rb reads bytes, wb writes bytes and ab appends bytes.

Read and copy a binary file 
with open("photo.jpg", "rb") as file:
    data = file.read()
print(type(data))
print(len(data))

with open("photo.jpg", "rb") as source:
    data = source.read()
with open("photo_copy.jpg", "wb") as destination:
    destination.write(data)
OUTPUT<class 'bytes'>
(Length depends on the file.)

For very large binary files, copy data in chunks instead of reading the entire file into memory.

Python maintains a file position indicating where the next read or write will occur. tell() returns the current position and seek() changes the position.

22

Fetching Something from the Web using urllib

Python can retrieve data from the Internet using libraries such as urllib. The urllib.request module provides urlopen() to access a web resource.

Fetch a web page 
from urllib.request import urlopen
url = "https://example.com"
with urlopen(url, timeout=10) as response:
    html = response.read().decode("utf-8")
print(html[:300])
OUTPUTFirst 300 characters of the returned HTML page (response may vary).

urlopen() sends a request; response.read() reads bytes; decode("utf-8") converts bytes to text. A website may block automated requests or change its response, so real applications should handle network errors.

Handle web access errors 
from urllib.request import urlopen
from urllib.error import URLError, HTTPError

url = "https://example.com"
try:
    with urlopen(url, timeout=10) as response:
        data = response.read().decode("utf-8")
        print(data[:200])
except HTTPError as error:
    print("HTTP error:", error.code)
except URLError as error:
    print("Network error:", error.reason)
except TimeoutError:
    print("The request timed out.")
