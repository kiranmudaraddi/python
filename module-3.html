PART A

Python Dictionaries

A dictionary stores data as key-value pairs. Keys are unique and hashable; values can be of different types. Dictionaries are mutable and preserve insertion order.

01

Creating and Accessing Dictionaries

Example: a student record stores name, USN and marks under meaningful keys.

Create and access 
student = {
    "name": "Ravi",
    "usn": "101",
    "marks": 85
}
print(student)
print(student["name"])
print(student.get("city"))
OUTPUT{'name': 'Ravi', 'usn': '101', 'marks': 85}
Ravi
None

dict[key] raises KeyError if a key is missing. get(key) returns None (or a supplied default) instead.

02

Adding, Updating and Removing Elements

Dictionary operations 
student = {"name": "Ravi", "marks": 80}
student["age"] = 18       # add
student["marks"] = 95     # update
student.pop("age")        # remove
print(student)
OUTPUT{'name': 'Ravi', 'marks': 95}
MethodPurpose
keys()Returns dictionary keys
values()Returns dictionary values
items()Returns key-value pairs
get()Safely accesses a value
update()Adds or updates pairs
pop()Removes a specified key
popitem()Removes last inserted pair
clear()Removes all pairs
copy()Creates a shallow copy
Traversing with items() 
student = {"name": "Ravi", "age": 18, "marks": 85}
for key, value in student.items():
    print(key, ":", value)
OUTPUTname : Ravi
age : 18
marks : 85
03

Nested Dictionaries

A dictionary can contain another dictionary. This is useful for storing multiple student records.

Student records 
students = {
    "s1": {"name": "Ravi", "marks": 85},
    "s2": {"name": "Priya", "marks": 90}
}
print(students["s1"]["name"])
for sid, record in students.items():
    print(sid, record["name"], record["marks"])
OUTPUTRavi
s1 Ravi 85
s2 Priya 90
PART B

NumPy – Numerical Python

NumPy is a Python library for numerical computing. It provides efficient arrays, matrices and mathematical functions.

04

Installing, Importing and Creating Arrays

Install using pip install numpy in a terminal (or %pip install numpy in Jupyter). Import with the common alias np.

1D and 2D arrays 
import numpy as np
one_d = np.array([10, 20, 30, 40])
two_d = np.array([[10, 20, 30],
                  [40, 50, 60]])
print(one_d)
print(two_d)
print(two_d[0, 0])
print(two_d[1, 2])
OUTPUT[10 20 30 40]
[[10 20 30]
[40 50 60]]
10
60

NumPy arrays are designed for numerical work and usually hold elements of a common data type. Python lists are more general-purpose and can hold mixed types.

Exact integer dtype may vary by platform. zeros() creates zeros, ones() creates ones, arange() generates a range, and linspace() creates evenly spaced values including both endpoints.

06

Arithmetic and Statistical Functions

Element-wise operations 
import numpy as np
a = np.array([10, 20, 30])
b = np.array([1, 2, 3])
print(a + b)
print(a - b)
print(a * b)
print(a / b)
OUTPUT[11 22 33]
[ 9 18 27]
[10 40 90]

Common statistical functions: np.sum(), np.mean(), np.max(), np.min(), np.median() and np.std().

Student marks analysis 
import numpy as np

print("Total:", np.sum(marks))

07

Indexing, Slicing and Reshaping

Indexing accesses one element. Slicing extracts a range; the stop index is excluded. Reshape changes dimensions while keeping the total number of elements unchanged.

Slicing and reshape 
import numpy as np
a = np.array([10, 20, 30, 40, 50])
print(a[0])
print(a[1:4])
print(a[:3])
print(a[2:])
b = np.arange(1, 7).reshape(2, 3)
print(b)
OUTPUT10
[20 30 40]
[10 20 30]
[30 40 50]
[[1 2 3]
[4 5 6]]
PART C

File Handling in Python

File handling allows a program to create, read, write and append data in files so information can be used after a program ends.

08

Opening Files and File Modes

Syntax: file = open("filename.txt", "mode")

ModePurpose
rRead; file must exist
wWrite; creates or truncates existing file
aAppend at the end
xCreate new file; fails if it exists
r+Read and write without truncating
w+Read and write; truncates existing file
a+Read and append

Warning: Opening an existing file in w mode erases its previous contents. Use a to add content at the end.

09

Writing, Reading, Appending and Closing

Write and read a student file 
with open("student.txt", "w") as file:
    file.write("Name: Ravi\\n")
    file.write("USN: 101\\n")
    file.write("Marks: 85\\n")

with open("student.txt", "r") as file:
    print(file.read())
OUTPUTName: Ravi
USN: 101
Marks: 85

The with statement automatically closes the file when the block finishes.

  • read() reads the whole file or a specified number of characters.
  • readline() reads one line.
  • readlines() returns remaining lines as a list.
  • write() writes a string.
  • close() closes a file opened manually.
Append and count lines 
with open("student.txt", "a") as file:
    file.write("Course: Python Programming\\n")

with open("student.txt", "r") as file:
    lines = file.readlines()
    print("Number of lines:", len(lines))
    print("First line:", lines[0].strip())
OUTPUTNumber of lines: 4
First line: Name: Ravi

tell() returns the current file pointer position; seek(position) moves it.
